# 智能企業永續平台｜專題介紹網站

靜態專題展示網站，介紹 AI 輔助永續資料整理、人工確認、MySQL 匯入及 Power BI 分析方向。

## 開啟方式

下載後以瀏覽器開啟 `index.htm`，保留所有 `.htm` 與 `assets/` 的相對位置。不需啟動後端。

## 頁面

- `index.htm`：專題緣起、特色與學術／實務貢獻。
- `team.htm`：六位組員資料、自我介紹與心得。
- `system01.htm`：Excel／CSV 上傳與資料讀取。
- `system02.htm`：AI 品質檢查與欄位判讀。
- `system03.htm`：人工修改與分析資料建模。
- `system04.htm`：MySQL 匯入、來源查閱與 Power BI 銜接。

本儲存庫僅收錄專題介紹網站，未包含實際系統後端、資料庫備份、本地模型及 API 金鑰。系統截圖為開發階段紀錄；組員照片目前為佔位圖。
